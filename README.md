**# 🎨 Ganpati Drawing with Python Turtle**

This project uses Python's built-in `turtle` library to create a beautiful and intricate drawing of Lord Ganesha. 🙏

---

## 📝 Description

The Python script `index.py` contains a sequence of `turtle` graphics commands to draw a complete picture of Ganpati. The drawing is broken down into logical parts like the trunk, eyes, crown, and limbs, making the code a great example of procedural art generation.

---

## 🖼️ Output

When you run the script, a `turtle` graphics window will open and you will see the image being drawn in real-time.

## 🚀 How to Run

No external libraries are needed to run this project, as `turtle` is part of the Python standard library.

---

### Prerequisites

✅ Python 3.x must be installed on your system.

---

### Steps

1.  Open your terminal or command prompt.
2.  Navigate to the directory containing the `index.py` file.
    ```sh
    cd path/to/ganpati_python_file
    ```
3.  Run the script with the following command:
    ```sh
    python index.py

A new window will appear and the drawing will begin.

---

## 💻 Code Structure

The code is organized into sections for drawing different parts of the figure:

  - Crown
  - Ears, Belly, Legs, and Hands
